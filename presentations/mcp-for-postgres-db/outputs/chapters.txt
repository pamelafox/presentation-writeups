This talk explores how to build MCP (Model Context Protocol) servers for PostgreSQL databases using Python and FastMCP. It covers a progression from exploratory servers where agents write full SQL queries to fully typed operational servers with maximum safety, discussing tradeoffs, failure modes, and tool design strategies at each level.
