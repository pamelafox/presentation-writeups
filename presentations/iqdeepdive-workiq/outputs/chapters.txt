Session 2 of the Microsoft IQ Deep Dive with Python series, presented by Ayça Baş. It covers Work IQ, the Microsoft 365 intelligence layer that gives agents access to work context — mail, meetings, chats, and documents — through A2A, MCP, and REST. The session walks through the 10 generic Work IQ tools in Python notebooks, uses Work IQ as a Foundry IQ knowledge source, wires it into a Microsoft Agent Framework agent, and finishes by turning that hosted agent into an Agent 365 autopilot with its own Microsoft 365 identity.
