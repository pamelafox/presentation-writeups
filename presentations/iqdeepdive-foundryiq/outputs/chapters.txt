Summary:
Part 1 of the "Microsoft IQ Deep Dive with Python" series introduces the Microsoft IQ family (Work IQ, Fabric IQ, Web IQ, Foundry IQ) and then goes deep on Foundry IQ, which is Azure AI Search. It covers knowledge bases, the data ingestion pipeline for unstructured documents, hybrid retrieval, the three retrieval reasoning effort levels, and how to connect multiple knowledge sources including search indexes and MCP servers like Web IQ. The second half shows three ways to use a Foundry IQ knowledge base as a tool inside a Python agent built with Microsoft Agent Framework, then deploys those agents to Foundry Agent Service hosted agents and publishes one to Teams.
